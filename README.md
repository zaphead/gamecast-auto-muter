# GameCast Auto-Muter

Watches your tab, mutes full-screen ads, unmutes the game.

## Install

1. Go to `chrome://extensions`, turn on Developer mode.
2. Load unpacked → select this folder.
3. Click the extension icon, paste your OpenAI API key, Save.
4. Open your game tab, hit Turn ON for this tab.

Checks every 5s. Game = unmute, ad = mute. Turns itself off on refresh/close.
